===========================================
# Media Studio CLI Help
===========================================
# Usage:
mda [[-h | --help] | <type> <action> [<value> [<extra>]]]

# Available flags:
-h, --help        :print this help.

# Available types:
app               :Ứng dụng GUI (Giao diện người dùng).
video             :Các tính năng xử lý video.
audio             :Các tính năng xử lý âm thanh.
image             :Các tính năng xử lý hình ảnh.
media             :Các tính năng xử lý media đa dụng.
dld               :Các tính năng tải xuống từ mạng xã hội (Downloader).

# Available actions:
## app:
   player     :Mở ứng dụng Video Player.

## video:
   rm-logo        :Xóa watermark/logo khỏi video tại vùng tọa độ x,y,w,h chỉ định.
                  // Vd: mda video rm-logo "D:\video.mp4" "24,21,135,44"
   frames         :Trích xuất khung hình video ra ảnh PNG với khoảng thời gian giãn cách (vd: 5s, 200ms, 2m). (Lưu vào thư mục riêng kèm timestamp)
                  // Vd: mda video frames "D:\video.mp4" 5s 50

## audio:
   extract        :Tách âm thanh từ video sang định dạng .wav hoặc .mp3.
                  // Vd: mda audio extract "D:\video.mp4" "D:\audio.mp3"

## image:
   flip           :Lật hình ảnh theo chiều ngang hoặc dọc từ absolute path.
                  // Vd: mda image flip "D:\image.jpg" horizontal
                  // Vd: mda image flip "D:\image.jpg" vertical "D:\image_flipped.jpg"

## media:
   slice          :Cắt một đoạn từ media tại khoảng thời gian cho trước (vd: 00:10-01:22). Tùy chọn [output_filename] để chỉ định tên file xuất.
                  // Vd: mda media slice "D:\video.mp4" 00:10-01:22 "clip1"
   part-size      :Chia nhỏ file media (.wav, .mp3, .mp4) thành các phần theo dung lượng MB chỉ định. Tùy chọn [limit] số phần đầu ra. (Lưu vào thư mục riêng kèm timestamp)
                  // Vd: mda media part-size "D:\video.mp4" 48 5
   part-time      :Chia nhỏ file media thành các phần dựa trên thời lượng (vd: 20s, 3m, 3p). Tùy chọn [limit] số phần đầu ra. (Lưu vào thư mục riêng kèm timestamp)
                  // Vd: mda media part-time "D:\video.mp4" 20s 5

## dld:
   ytb, ytb-music, fb, insta, tiktok, bilibili, scloud, spot   :Tải nội dung từ các nền tảng tương ứng. YouTube/Facebook/Instagram/TikTok/Bilibili/SoundCloud dùng yt-dlp + aria2; Spotify dùng spotDL. Hỗ trợ alias bili/bilili cho Bilibili. Hỗ trợ option: best-vid, good-vid, audio, sub. Riêng Spotify chỉ tải audio. Nếu bỏ qua option, mặc định dùng good-vid. Dùng --threads để chỉ định số luồng tải, mặc định 4. LƯU Ý: Spotify yêu cầu cấu hình SPOTIFY_CLIENT_ID và SPOTIFY_CLIENT_SECRET trong file .env.
                  // Vd: mda dld bili "https://bilibili.com/..." audio --filename "my_audio" --folder "C:\Downloads" --format "mp3" --threads 8
   douyin         :Tải Douyin bằng công cụ chuyên dụng (jiji262/douyin-downloader) hỗ trợ no-watermark, deduplication. Nhận --mode [post|like|mix|music|favorites] cho tải hàng loạt. LƯU Ý: Yêu cầu bắt buộc cấu hình 5 giá trị cookie Douyin trong file .env để không bị chặn.
                  // Vd: mda dld douyin "https://v.douyin.com/..."
                  // Vd: mda dld douyin "https://www.douyin.com/user/..." --mode post --folder "data/video/output"
                  // Vd: mda dld bili "https://bilibili.com/..." audio --filename "my_audio" --folder "C:\Downloads" --format "mp3" --threads 8
                  // Vd: mda dld soundcloud "https://soundcloud.com/artist/track" audio --format "mp3"
                  // Vd: mda dld spotify "https://open.spotify.com/playlist/..." audio --folder "C:\Downloads" --format "mp3"

# Example:
Lệnh `mda app player` sẽ khởi động ứng dụng Video Player.
Lệnh `mda audio extract "input.mp4" "output.wav"` sẽ tách âm thanh từ video sang định dạng WAV.
